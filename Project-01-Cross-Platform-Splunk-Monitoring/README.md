Project 1: Cross-Platform Security Monitoring with Splunk

Overview

A hands-on SOC project demonstrating security monitoring and investigation across Windows and Linux using Splunk Enterprise.

Objectives

- Monitor Windows Security Events
- Investigate Linux SSH authentication
- Detect successful and failed logons
- Monitor privileged activity and process creation
- Develop SPL searches and a centralized SOC dashboard
