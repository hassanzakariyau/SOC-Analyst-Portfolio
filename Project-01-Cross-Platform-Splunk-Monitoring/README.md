Project 1: Cross-Platform Security Monitoring with Splunk
Overview
A hands-on SOC project demonstrating security monitoring and investigation across Windows and Linux using Splunk Enterprise.
Objectives
- Monitor Windows Security Events.- Investigate Linux SSH authentication.- Detect successful and failed logons.- Monitor privileged activity and process creation.- Develop SPL searches and a centralized SOC dashboard.
Environment
- Windows 11 Pro- Ubuntu (WSL)- Splunk Enterprise- Windows Security Event Logs- Linux authentication and system logs
Investigations
- Windows successful logons — Event ID 4624- Windows failed logons — Event ID 4625- Windows privileged logons — Event ID 4672- Windows process creation — Event ID 4688- Linux failed SSH authentication- Linux successful SSH authentication
Dashboard
Cross-Platform SOC Monitoring dashboard containing seven panels for Windows and Linux security activity.
Skills Demonstrated
- SIEM monitoring- SPL searches- Windows log analysis- Linux authentication investigation- Security event correlation- Dashboard development- Basic SOC investigation and reporting
Evidence
Screenshots, investigation notes, and SPL queries are included in this project.
Disclaimer
All security activities were performed in a controlled personal lab environment for educational purposes.
